# ALFHA ModelHub v0.2.0 draft

ALFHA ModelHub adds a local browser workspace, evidence-based routing, and
engineering benchmarks that grade submitted code and SQL in isolated
containers.

- The browser workspace supports chat, model comparison, and paginated
  execution history. [Windows startup guide](../README.md#local-web-ui-on-windows-11)
- Routing can preview a model choice and optionally dispatch generation.
  Decisions use curated benchmark reports and include reasons for selection
  or fallback. Optional cloud dispatch verifies catalog pricing and sends
  zero-price limits. [Routing design](routing-design.md)
- The engineering suite covers 24 objective tasks. The Java coding pilot
  records sandbox outcomes alongside saved benchmark reports.
  [Benchmark guide](benchmarks.md)
- The offline evaluation workflow adds four held-out graders, provenance
  checks, a local collection script, and paired campaign summaries.
  [Repeatability protocol](benchmark-repeatability.md)
